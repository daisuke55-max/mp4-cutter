# 動画カット・圧縮ツール (mp4-cutter)

数時間の動画から、必要な部分だけを切り出して、解像度と画質を下げて小さく保存する Windows 用のツールです。

- 動画を1本でも、複数でも選べます(rm・wmv・flv なども使えます)
- 切り出したい範囲を、いくつでも選べます。動画をまたいで、順番につなげて1つのファイルにもできます
- 範囲ごとに、動画を横向き・縦向きに回せます
- 解像度(1080p〜360p)と画質を選んで、ファイルを小さくできます
- 動画は、あなたのパソコンの中だけで処理されます。インターネットには送られません
- 元の動画は、そのまま残ります
- 無料で使えます。ただし、**自己責任でお使いください**(下の「注意」を読んでください)

## ダウンロード

1. このページの緑の **Code** ボタンを押し、**Download ZIP** を押します
2. ダウンロードした ZIP を、右クリックして「すべて展開」します
3. 展開してできたフォルダを、好きな場所に置きます(デスクトップなど)

## 使い方

### 最初の1回だけ

フォルダの中の **`最初の準備.bat`** をダブルクリックします。
動画を処理するのに必要なもの(Node.js と ffmpeg)が、自動で入ります。「はい」を押す画面が出たら、押してください。

> 「Windows によってPCが保護されました」と出たら、「詳細情報」→「実行」を押してください。

### 使うたび

画面は、パソコンの画面1枚に収まるように並んでいます。左が「2 範囲を決める」(動画のプレビュー)、右上が「1 選んだ動画」、右下が「3 書き出す内容の一覧」です。

1. **`動画カット起動.bat`** をダブルクリックします(ブラウザに操作画面が開きます)
2. 右上の「1 選んだ動画」の「動画選択」で、動画を選びます。複数の動画をまとめて選ぶときは、Ctrl を押しながらクリックします(あとから追加もできます)
   - 選んだ動画は、右上の「1 選んだ動画」に並びます。何も指定しなければ、**まるごと**使います
3. 一部だけ使いたいときは、左の「2 範囲を決める」で、動画を見ながら、残したい範囲を決めて「この範囲を追加」を押します(何か所でも、どの動画からでも追加できます)
   - 別の動画の範囲を決めるときは、「1 選んだ動画」の「範囲を決める」を押します
   - 再生・停止は、「再生 / 停止」ボタン、スペースキー、プレビューの画面のクリックで行えます
   - 「この動画を、まるごと追加」を押すと、動画全体を、向きを変えて入れられます
4. 右下の「3 書き出す内容の一覧」で、確認します。「↑」「↓」で順番を変えたり、「削除」で外したり、「向き」「枠への入れ方」を変えたりできます
5. 「書き出しへ進む」を押すと、書き出しの画面が開きます。解像度と画質を選び、「書き出す」を押します
   - 「順番につなげて、1つのファイルにする」にチェックを入れると、一覧の上から順につなげて1本の動画になります
   - チェックを外すと、一覧の1つずつが、別のファイルで保存されます
   - 書き出しの画面を閉じても、書き出しは続きます。進み具合は、「書き出しへ進む」のボタンに出ます
6. 終わったら、黒い画面(コマンドの窓)を閉じます

動画を1本だけ選んで、そのまま書き出せば、mp4 への変換になります(rm・wmv・flv なども)。

解像度・画質・処理の速さ・「音も残す」・「つなげる」の選択は、次に使うときも覚えています。

「処理の速さ」は、「速い」「ふつう」「じっくり」から選べます。「速い」は早く終わりますが、画質を同じにしても、ファイルが少し大きくなることがあります。時間がかかるときは、「速い」にしてください。

### 向きを変える(寝かす・起こす)

一覧の「向き」で、1つずつ選べます(「この範囲だけ右に90度」ができます)。「そのまま」「右に90度」「左に90度」「180度」から選べます。向きは、動画ごとに違うので、次に使うときは覚えていません。プレビューには、「仕上がりの形で見る」で、回した向きも出ます。

### 動画の大きさ(枠への入れ方)を変える

一覧の「枠への入れ方」で、1つずつ選べます(「範囲を追加」の横でも選べます)。
- **枠に収める(100%)**(初めの設定): 全体が見えるように入れます。余った所は、黒い帯になります
- **110%〜200%**: その割合に大きくします(10%きざみ)。はみ出た上下・左右は、切れます
- **枠いっぱい**: 枠いっぱいに広げます。はみ出た所は、切れます(例: 横にした動画の上下を切って、横幅いっぱいにする)

切れる位置は、真ん中を基準にします。

「2 範囲を決める」のプレビューは、「仕上がりの形で見る」にチェックが入っていると、書き出したときの画面の形で出ます。「向き」や「枠への入れ方」を変えると、見た目がその場で変わります(見た目の確認用です。実際の書き出しと、少しずれることがあります)。一覧の「見る」を押すと、その素材の設定で見られます。チェックを外すと、元の動画のまま見られます。

### 大きさや向きが違うものをつなげるとき

動画の大きさやコマ数、向きがばらばらでも、そろえてからつなげます。全体の大きさは、横長のものに合わせます。縦長のものは、左右に黒い帯がつきます(横長が1つもないときは、縦が一番大きいものに合わせます)。

## 最新版に更新する

フォルダの中の **`更新.bat`** をダブルクリックします。最新版が自動でダウンロードされ、入れ替わります。
(ツールを開いていた場合は、黒い画面を閉じて、「動画カット起動.bat」を開き直してください)

## 動作環境

- Windows 10 / 11
- ブラウザ(Chrome、Edge など)
