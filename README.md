# 動画カット・圧縮ツール (mp4-cutter)

数時間の動画から、必要な部分だけを切り出して、解像度と画質を下げて小さく保存する Windows 用のツールです。

- 切り出したい範囲を、複数か所まで選べます(つなげて1つのファイルにもできます)
- 解像度(1080p〜360p)と画質を選んで、ファイルを小さくできます
- 動画は、あなたのパソコンの中だけで処理されます。インターネットには送られません
- 元の動画は、そのまま残ります
- 無料で使えます。ただし、**自己責任でお使いください**(下の「注意」を読んでください)

## ダウンロード

1. このページの緑の **Code** ボタンを押し、**Download ZIP** を押します
2. ダウンロードした ZIP を、右クリックして「すべて展開」します
3. 展開してできたフォルダを、好きな場所に置きます(デスクトップなど)

## 使い方

### 最初の1回だけ

フォルダの中の **`最初の準備.bat`** をダブルクリックします。
動画を処理するのに必要なもの(Node.js と ffmpeg)が、自動で入ります。「はい」を押す画面が出たら、押してください。

> 「Windows によってPCが保護されました」と出たら、「詳細情報」→「実行」を押してください。

### 使うたび

1. **`動画カット起動.bat`** をダブルクリックします(ブラウザに操作画面が開きます)
2. 「動画を選ぶ」で動画を選びます
3. 動画を見ながら、残したい範囲を決めて「この範囲を追加」を押します(何か所でも追加できます)
4. 解像度と画質を選び、「書き出す」を押します
   - 「範囲をつなげて、1つのファイルにする」にチェックを入れると、上から順につなげて1本の動画になります
   - チェックを外すと、範囲ごとに別のファイルで保存されます
5. 終わったら、黒い画面(コマンドの窓)を閉じます

解像度・画質・「音も残す」・「つなげる」の選択は、次に使うときも覚えています。

### 複数の動画を、1つの mp4 につなげる(rm もOK)

画面の下の「複数の動画を、順番につなげて1つの mp4 にする」を開きます。

1. 「つなげる動画を選ぶ」で、動画をまとめて選びます(Ctrl を押しながらクリック)。最初は、ファイル名の順に並びます
2. 「↑」「↓」で順番を入れ替えます
3. 解像度と画質を選び、「つなげて書き出す」を押します

大きさやコマ数がばらばらの動画でも、そろえてからつなげます(大きさは、一番縦が大きい動画に合わせます)。
rm(RealMedia)・wmv・flv など、mp4 以外の動画も使えます。動画ごとの切り出しはできません(動画まるごと)。

## 最新版に更新する

フォルダの中の **`更新.bat`** をダブルクリックします。最新版が自動でダウンロードされ、入れ替わります。
(ツールを開いていた場合は、黒い画面を閉じて、「動画カット起動.bat」を開き直してください)

## 動作環境

- Windows 10 / 11
- ブラウザ(Chrome、Edge など)

## 注意

- **自己責任でお使いください。** 作者は、このツールを使って起きた問題について、責任を負いません。大事な動画は、必ずバックアップしてから使ってください
- 書き出しには時間がかかります。目安は、動画の長さと同じくらいです(パソコンの性能で変わります)。動画の一部だけを残す場合は、残した部分の長さが目安です
- ブラウザで再生できない形式の動画は、プレビューが出ないことがあります。その場合は、時間を直接入力してください
- ffmpeg は、このツールには含まれていません。「最初の準備.bat」が、公式の配布元から入れます
